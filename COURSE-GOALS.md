# AI 102: course and Eve's purpose

Every lesson has four distinct purposes: teach the concept, demonstrate a worked case, apply it in practice, and summarise the achieved outcome. Student-facing titles name the actual concept and activity, not “learn ideas” or “see ideas”. Practice does not repeat the lesson definition; worked cases differ from practice cases where an answer is being tested. Eve receives only the current stage. Concept questions use multiple choices with plausible alternatives and explanatory retry feedback; genuine predictions and personal explanations remain in the learner's own words. Day 7 ends with a journey recap and an honest completion page; all lessons must be completed for the course-complete message. Stage state is saved per learner without erasing existing work.

For now, every agent uses English. New presets and resumed agents use English; language selection is not offered. Existing learner work is retained.

The course is a coherent beginner journey to understand how AI works, practise each new idea, and build an AI agent the learner can explain and test. Creating an agent is the practical destination, not a substitute for understanding AI. Eve is a warm African teacher and a companion through each current activity. The shared warm classroom interface keeps each step clear and inviting, without gender-targeted decoration.

AI 102 teaches complete beginners how to create AI agents from three preset starting ideas: Biology tutor, Business helper and Personal coach. These cover education, business and everyday goal-setting. An agent uses an existing AI model, clear instructions, reference information and tools to answer requests and carry out specific tasks. There is no model-training activity or GPU requirement in this course.

The learner finishes by explaining their agent’s job, saving its configuration, inspecting its tool actions, testing normal and uncertain requests, and recognising its limits. Local practice demonstrates these components; a connected existing-model service is needed for live model answers.

| Page | What the learner should understand | Small activity |
| --- | --- | --- |
| Start here | An AI agent needs a clear job | Choose one of three presets and name it in the pop-up; English is automatic |
| Day 1 | AI learns patterns and can make mistakes | Apply the distinctions through concept choices, a prediction and a personal explanation |
| Day 2 | Tokens are small pieces of text | Inspect the illustrated text pieces |
| Day 3 | Examples guide useful answers, honest limits and focus; they do not guarantee correctness | Identify the main response pattern in three suggested pairs; no authoring or approval required |
| Day 4 | Instructions guide behaviour; temperature changes variety | Choose a starting setting with a justified reason; preset instructions are supplied |
| Day 5 | An agent combines a job, instructions, examples and information | Assemble one setup and check its collected parts; no version management or artificial answer comparison |
| Day 6 | Tools perform specific actions | Run the preset-relevant knowledge search, calculator or task list and inspect the local result |
| Day 7 | The whole AI agent needs testing before use | Review normal, uncertain and tool requests using evidence-based multiple-choice checks, then reflect and complete the course |

Eve teaches the current page and current step. She uses the learner's name, chosen preset, visible work and recent conversation. She acknowledges a clear answer, explains one idea, and invites one small action. When a learner struggles she changes the explanation; she does not diagnose a fixed learning style or repeatedly ask generic comprehension questions. Speech does not automatically save form fields.

The page and Eve share the goals in curriculum.js. Task actions update her context. All days remain open. The diagnostics panel is available but collapsed. Conversation state stays in the existing browser project; this update does not reset learners.

Local answer comparisons demonstrate saved configurations and example responses. Calculator, notes and task tools carry out local actions. Eve's teaching service is separate from the learner's agent. Text-piece colouring is illustrative, not a real model tokenizer. Saving an agent does not train a model or publish an online service. AI 102 does not offer a model-training workflow.
